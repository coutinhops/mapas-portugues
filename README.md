# 55 Mapas Mentais de Português

Landing page estática em português de Portugal, com identidade visual vermelha e CTAs de compra verdes.

## Publicar na Vercel
Importar este repositório, escolher Other, sem build, diretório de saída `.`. O ponto de entrada é index.html.

A pasta imagens contém as imagens originais e variantes WebP responsivas. Os checkouts Essencial e Completo são os links Hotmart já configurados.

Os metadados canonical/OG e sitemap apontam para https://mapasportugues.vercel.app/. Ao usar outro domínio, atualize essas referências.

Consulte RELATORIO-PAGESPEED.md para as alterações e limites de verificação.
